# Source origins

This repository consolidates custom integration source. It does not replace the upstream Paper, squaremap or Pumpkin projects, and it contains no live world or player records.

Consolidation preserved the original directories, histories and working changes without moving or resetting them. The cyhdev application received the dimension and transport feature edits separately; those changes are identified by their source commits above. This repository uses source snapshots so unrelated website history and private deployment data are not copied.

The latest cyhdev source revision reflected here is `af591ae85e40a81473125943363890622e0aa067`, which restores 256 CSS-pixel prediction and highlight tiles at every browser zoom, admits up to 2,048 active targets, and bounds tile data at 256 MiB with four concurrent requests. Coverage tests include large-view resizing, panning and highlights. The earlier coarsening fix at `11189aa95a074a9f64e149dbb64432614e210609` is superseded. Its history includes the dimension implementation at `7bac701c38099def05f8406749e3f0a7d88a7994`, tile codecs at `a2c5b2256281eae11b8f5708120642d3e1de868e`, surface projection at `da02d5365739ee4b03463529cc446b5e36e3cde1`, waypoint labels at `e95b5a08f11639f09c8636def11ddc62c351e851`, centered scale at `555a948391b4b28ffc1f89ee5940d0e117a28e21`, biome picker at `057b8e11a0aac32dc3b9cd034b79112f0128f730`, and overlay declarations at `88a332c8495e31831195650a416e37f4eaef74cc`. The adapter and reusable map package retain per-file source hashes in their `SOURCE_SNAPSHOT.json` manifests; adapted documentation records both original and consolidated hashes. The manifests' `sourceCommit` field marks the latest source revision, while unchanged files can retain hashes from earlier revisions.

The clean [squaremap](https://github.com/jpenilla/squaremap) checkout and [Pumpkin contribution fork](https://github.com/younghyun1/Pumpkin) remain external dependencies and projects. Preserve exact dependency revisions and their licenses instead of copying their complete servers and assets here. The empty `squaremap_rs` Hello World prototype has no implementation to consolidate.
